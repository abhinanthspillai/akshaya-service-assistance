# Akshaya UI Design Source

## References
- `references/login_reference.png` — PRIMARY visual/theme reference.
- `references/dashboard_reference.png` — PRIMARY authenticated layout/structure reference.

## Rules
Use the login reference's purple/blue/cyan identity across the whole app. Use the dashboard reference for sidebar proportions, card hierarchy, information density, tables and topbar structure. Do not copy its green palette or unrelated environmental content.

## Initial tokens
- Primary: `#5538FF`
- Primary dark: `#3923D9`
- Blue: `#4D8CFF`
- Cyan: `#86DFF3`
- Background: `#F6F4FF`
- Surface: `#FFFFFF`
- Text: `#17141F`
- Secondary text: `#777382`
- Border: `#E7E3F2`

Brand gradient: `linear-gradient(135deg, #8AE5F6 0%, #4D8CFF 30%, #5538FF 58%, #D399FF 100%)`

Character: simple, professional, calm, trustworthy, service-oriented. Avoid unsupported social login, unrelated charts, excessive glassmorphism/animation, and decorative complexity.
