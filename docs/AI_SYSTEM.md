# AI_SYSTEM

No runtime AI subsystem is required for the approved Phase 1 core workflow.

Claude, Codex and Antigravity are development tools, not deployed application agents.

Phase 2 intelligent document upload assistance/pre-validation or other ML/AI capabilities require a separate approved architecture, evaluation set, security model and fallback behavior before implementation.

Therefore Phase 1 must not add:
- LLM API dependencies
- vector databases
- RAG
- autonomous agent execution
merely to satisfy a generic architecture template.
