# Claude Project Context
Akshaya is an MCA service-assistance platform connecting citizens and Akshaya Centres through an end-to-end managed request workflow.

Use the repository specs, not conversational history, as implementation truth.

Core roles: Citizen, Centre Employee, Centre Administrator, System Administrator.
Core service classes: A digital/no normal mandatory physical interaction; B limited interaction; C substantial physical participation/procedure.
Phase 1 builds the reliable transactional workflow. Phase 2 extends it with advanced/intelligent capabilities.
